# Tithimala (तिथिमाला)

An open-source, ad-free Nepali (Bikram Sambat) calendar for Android.

Tithimala is offline by default, collects no user data, and contains no ads, tracking, accounts, news, or horoscope feeds.

## Status

Active development toward v0.1.0.
